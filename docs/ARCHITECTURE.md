# Калькулятор-тайник — архитектура

Статус: **согласовано, код ещё не начат.**

## 1. Что делаем

Android-приложение, которое снаружи выглядит и работает как обычный калькулятор.
Если набрать секретный PIN и нажать «=», открывается зашифрованный тайник для
фото, видео и PDF-документов. Спрятанные файлы не видны ни в галерее,
ни в файловых менеджерах, ни в других приложениях.

## 2. Решения, принятые на интервью

| Вопрос | Решение | Почему |
|---|---|---|
| Платформа | Только Android | Установка APK бесплатная и простая, без магазина |
| Резервные копии | **Нет** | Максимальная секретность. Цена: удаление приложения, «Очистить данные», сброс или потеря телефона, забытый PIN = файлы потеряны навсегда |
| Дополнительно | Фальшивый PIN (второй, безобидный тайник) | Защита, если заставят открыть |
| Объём | Много, включая большие видео | Шифрование кусками, просмотр видео без расшифровки на диск |
| Документы | Только PDF, просмотр внутри приложения | Расшифрованная копия не передаётся другим приложениям |
| Оригинал после переноса | Удаляется (Android покажет системное подтверждение) | Иначе прятать бессмысленно |
| Маскировка | Значок и название «Калькулятор» | Не выделяется |
| Отпечаток / лицо | Нет, только PIN | Плохо сочетается с фальшивым PIN, PIN нельзя «приложить» силой |
| Камера внутри, фото взломщика | Не делаем | Не выбраны, держим приложение простым |

## 3. От чего защищаемся, а от чего нет

**Защищает:**
- человек взял разблокированный телефон, листает галерею и файлы;
- кто-то открыл «Калькулятор»: он работает как калькулятор, неверный PIN просто даёт результат вычисления;
- вас заставили открыть тайник: вы вводите фальшивый PIN;
- файлы скопировали с телефона (даже с root-доступом): без PIN *и* без защищённого чипа этого телефона их не расшифровать.

**Не защищает (ограничения, о которых нужно знать):**
- **копии в облаке.** Если в Google Фото включена автозагрузка, оригинал уже в облаке, и удалять его оттуда нужно вручную;
- **вирус или шпионская программа на телефоне,** которая видит экран в момент просмотра;
- **размер данных.** Специалист может увидеть, что приложение занимает, например, 5 ГБ. Поэтому в фальшивый тайник стоит положить правдоподобное содержимое;
- **забытый PIN.** Восстановления нет by design.

## 4. Как устроен вход

```
Значок «Калькулятор»
   │
   ▼
Калькулятор (работает по-настоящему: + − × ÷ %, скобки не нужны)
   │  пользователь нажал «=»
   ▼
Введённая строка — только цифры, длиной 6–12?
   ├─ нет  → обычное вычисление
   └─ да   → проверка PIN по ОБОИМ слотам (всегда оба, чтобы время было одинаковым)
              ├─ слот A подошёл → тайник A
              ├─ слот B подошёл → тайник B
              └─ ни один        → показать число как результат, ничего не выдавать
```

- **Первый запуск.** Один раз показывается экран «Придумайте PIN (минимум 6 цифр)» с повтором. После этого приложение всегда открывается как калькулятор.
- **Фальшивый PIN** задаётся в настройках внутри настоящего тайника.
- **Два слота существуют всегда.** Если фальшивый PIN не задан, слот B заполнен случайными данными, поэтому нельзя понять, есть второй тайник или нет. Какой слот «настоящий», не хранится нигде.
- **Подбор PIN.** Блокировку после ошибок сделать нельзя: неверный PIN выглядит как обычное вычисление. Защита — медленная проверка (Argon2id, около 0,5 с на слот) плюс привязка к чипу телефона (см. ниже).

## 5. Шифрование

Используем **Google Tink** — поддерживаемую библиотеку Google. Не пишем криптографию сами.
(`androidx.security:security-crypto` / `EncryptedFile` в 2025 году объявлены устаревшими, их не берём.)

**Ключи (для каждого слота):**

```
PIN ──Argon2id(соль слота, ~64 МБ памяти, ~0,5 с)──► ключ из PIN
                                                       │
Мастер-ключ тайника (случайный, 256 бит, Tink keyset) ─┘ шифруется ключом из PIN (AES-256-GCM)
   │
   └─ результат ещё раз шифруется ключом из Android Keystore
      (неизвлекаемый ключ, хранится в защищённом чипе телефона)
   ▼
slot_A.bin / slot_B.bin
```

- Без Keystore этого телефона PIN не подобрать, даже скопировав файлы: подбирать придётся на самом телефоне, по ~1 с на попытку.
- Мастер-ключ живёт в памяти только пока тайник открыт. При блокировке он стирается.

**Файлы:**
- **Содержимое.** Tink `StreamingAead`, режим `AES256_GCM_HKDF_1MB`: файл шифруется кусками по 1 МБ, каждый кусок проверяется на целостность. Испорченный файл даёт ошибку, а не «мусор».
- **Имена на диске** случайные (`a8f3…e1.bin`). Настоящее имя, тип, дата и размер хранятся только в зашифрованном оглавлении.
- **Миниатюры** — отдельные маленькие зашифрованные файлы.
- Файлы обоих тайников лежат в **одной общей папке**, по именам не понять, чьи они.

## 6. Хранение на диске

Всё лежит во внутренней папке приложения (`/data/data/<пакет>/files`). Другие приложения и галерея её не видят.

```
files/
  slot_A.bin            зашифрованный мастер-ключ слота A
  slot_B.bin            то же для слота B (или случайные байты)
  index_<hash>.bin      зашифрованное оглавление каждого тайника
  blobs/<random>.bin    зашифрованные файлы и миниатюры обоих тайников
  tmp/                  незавершённые операции, очищается при каждом запуске
```

- Автоматическая резервная копия Android **выключена** (`allowBackup=false`, `dataExtractionRules` исключают всё). Иначе данные утекли бы в Google Drive.
- Оглавление записывается атомарно: сначала во временный файл, потом мгновенное переименование. Если выключится телефон, оглавление не испортится.

## 7. Перенос файла в тайник (порядок важен для надёжности)

1. Проверить, что свободного места хватит (≈ размер файла + запас).
2. Прочитать оригинал и зашифровать его кусками в `tmp/`.
3. **Проверить:** полностью расшифровать результат и сверить размер и контрольную сумму с оригиналом.
4. Переместить из `tmp/` в `blobs/` и обновить оглавление.
5. **Только после этого** попросить Android удалить оригинал (`MediaStore.createDeleteRequest`, одно системное окно на всю пачку).

Если на любом шаге сбой или выключение, оригинал остаётся на месте, а мусор в `tmp/` удалится при следующем запуске. Пропасть файл не может.

**Выбор файлов:**
- **Фото и видео:** собственный экран выбора на основе `MediaStore`, с разрешением на доступ к медиа. Системный Photo Picker не подходит: файлы, выбранные через него, нельзя удалить из галереи.
- **PDF:** системный выбор документов (`ACTION_OPEN_DOCUMENT`), удаление оригинала через `DocumentsContract.deleteDocument`, если источник это позволяет; иначе подсказка удалить вручную.
- Работа идёт в фоне (WorkManager) с полосой прогресса. Большое видео не вешает интерфейс.

## 8. Просмотр и возврат

- **Фото:** расшифровка в память, на диск ничего не пишется.
- **Видео:** плеер Media3 (ExoPlayer) со своим источником данных, который расшифровывает нужный кусок на лету (`newSeekableDecryptingChannel`). Перемотка работает, расшифрованной копии нет.
- **PDF:** отрисовка постранично из памяти. Если на прототипе это окажется ненадёжным, запасной вариант — временная копия во внутренней папке, которая удаляется при закрытии и при запуске.
- **Вернуть в галерею:** расшифровка обратно в «Изображения», «Фильмы» или «Загрузки», затем удаление из тайника.
- **Удалить из тайника:** удаляются зашифрованный файл и запись в оглавлении.

## 9. Защита интерфейса

- Тайник запирается сразу, как приложение уходит с экрана (сворачивание, звонок, выключение экрана).
- В тайнике запрещены скриншоты и запись экрана (`FLAG_SECURE`).
- В «Недавних приложениях» видна только картинка калькулятора.
- Нет уведомлений и виджетов, которые могли бы выдать тайник.

## 10. Технологии

| Что | Чем |
|---|---|
| Язык | Kotlin |
| Интерфейс | Jetpack Compose |
| Шифрование | Google Tink + Android Keystore |
| Ключ из PIN | Argon2id (конкретную библиотеку выберем и проверим при реализации) |
| Видео | AndroidX Media3 (ExoPlayer) |
| Фоновые задачи | WorkManager |
| Минимальный Android | 8.0 (API 26), это около 97% телефонов |

## 11. Сборка и установка

- **Сборка в облаке.** GitHub Actions на каждый push собирает APK. На тег версии (`v1.0.0`) он публикуется в GitHub Releases. Свой компьютер и Android Studio не нужны. **Расходы: 0** (бесплатного лимита GitHub хватает с запасом).
- **Установка.** Скачать APK на телефон → разрешить установку из этого источника → установить.
- **Проверка разработчиков Google (2026–2027).** Сейчас она обязательна только в Бразилии, Индонезии, Сингапуре и Таиланде, по всему миру — с 2027 года. До перехода либо используется «расширенная установка» (один раз: перезагрузка и 24 ч ожидания), либо бесплатный любительский аккаунт разработчика (до 20 устройств, без платы и документов).
- **⚠️ Ключ подписи.** APK подписывается ключом. Он хранится в секретах GitHub, а **копия — у владельца в надёжном месте** (менеджер паролей). Если ключ потерять, обновление не встанет поверх старой версии. Придётся удалять приложение, а с ним удалятся все спрятанные файлы.

## 12. Структура проекта

```
app/src/main/java/.../
  calculator/   калькулятор: разбор выражения, экран
  auth/         первый запуск, проверка PIN, слоты, Argon2, Keystore
  vault/        мастер-ключ, оглавление, хранилище blobs, атомарная запись
  importer/     выбор файлов, шифрование, проверка, удаление оригинала
  viewer/       фото, видео (Media3 DataSource), PDF
  settings/     смена PIN, фальшивый PIN
.github/workflows/  сборка APK и релиз
```

## 13. План работ

1. **Каркас.** Проект, рабочий калькулятор, сборка APK в GitHub Actions. Ставим на телефон и проверяем установку.
2. **Ядро шифрования + тесты.** Слоты, ключи, шифрование файлов, оглавление. Автотесты: верный и неверный PIN, повреждённый файл, оборванная запись, файл 2+ ГБ.
3. **Вход.** Первый запуск, PIN через «=», два слота, автоблокировка.
4. **Импорт.** Фото и видео из галереи, PDF, проверка, удаление оригиналов.
5. **Просмотр.** Сетка миниатюр, фото, видео с перемоткой, PDF.
6. **Управление.** Вернуть в галерею, удалить, смена PIN, фальшивый PIN.
7. **Укрепление и проверка на реальном телефоне.** FLAG_SECURE, недавние приложения, бэкап выключен, проверка, что в «Корзине» галереи ничего не осталось.

## 14. Что проверить на реальном телефоне

- Не оставляет ли галерея производителя (Samsung, Xiaomi и т.д.) удалённые оригиналы в своей «Корзине».
- Работу с правами доступа к медиа на Android 14+ (режим «выбрать некоторые фото»).
- Скорость Argon2 на конкретном телефоне, чтобы подстроить параметры (цель — 0,3–0,7 с).
