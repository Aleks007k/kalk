# Калькулятор

Приложение для Android, которое выглядит и работает как обычный калькулятор.
Внутри — скрытый зашифрованный тайник для файлов (открывается секретным PIN
после нажатия «=»). Подробности — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

**Сейчас готово (версия 0.8.0):**
- рабочий калькулятор;
- вход в тайник: PIN + «=», код восстановления, автоблокировка;
- добавление фото, видео и файлов с проверкой и удалением оригиналов;
- просмотр фото и видео на весь экран: листание, увеличение пальцами (и у видео), перемотка видео ползунком и кнопками ±10 секунд;
- просмотр PDF (страницы листаются вверх-вниз, увеличение пальцами);
- заметки: просмотр, правка с автосохранением, новые — кнопкой «+ Заметка»;
- возврат файла обратно в Галерею или «Загрузки» (долгое нажатие или «⋮» → «Восстановить»);
- размер плиток меняется щипком двумя пальцами, как в Галерее;
- два раздела: «Фото и видео» (сеткой) и «Файлы» (документы и заметки списком);
- настройки (шестерёнка вверху): смена PIN, новый код восстановления и фальшивый PIN — второй, безобидный тайник на случай, если заставят открыть.

Все этапы плана готовы, проверка на телефоне пройдена.

## Как получить приложение на телефон

Приложение собирается автоматически на серверах GitHub. Ваш компьютер не нужен.

### Способ 1. Из раздела Releases (самый простой)

Появляется, когда выпущена версия (есть «тег»).

1. Откройте на телефоне страницу репозитория → **Releases**.
2. Скачайте файл **Calculator.apk**.
3. Установите (см. ниже «Установка на Samsung»).

> Если раздел Releases пуст — попросите меня «выпустить версию», и я создам тег:
> через пару минут там появится готовый файл.

### Способ 2. Из раздела Actions (пока нет релиза)

1. Вкладка **Actions** → последний зелёный запуск **Build APK**.
2. Внизу, в разделе **Artifacts**, скачайте **Calculator-apk** (придёт ZIP-архивом).
3. Распакуйте — внутри `Calculator.apk`.

## Установка на Samsung Galaxy S21 Ultra (One UI 7)

1. **Настройки → Безопасность и конфиденциальность → Автоблокировщик** — выключить.
   Samsung по умолчанию блокирует установку приложений не из магазина.
2. Откройте скачанный `Calculator.apk` (через «Загрузки» или уведомление).
3. На запрос «Разрешить установку из этого источника?» — разрешить → **Установить**.
4. Если появится предупреждение Play Protect «Неизвестный разработчик» —
   «Подробнее» → «Всё равно установить».
5. После установки Автоблокировщик можно включить обратно.

**Если Android не даёт поставить обновление** (Google вводит проверку
разработчиков: с 30.09.2026 — в Бразилии, Индонезии, Сингапуре и Таиланде,
в остальных странах — с 2027 года). Уже установленный калькулятор продолжает
работать. Чтобы ставить обновления, один раз включите разрешение:
1. Включите «Параметры разработчика»: Настройки → Сведения о телефоне →
   Сведения о ПО → 7 раз нажмите «Номер сборки».
2. Настройки → Параметры разработчика → «Apps from unverified developers»
   (по-русски название может отличаться) → включить, подтвердить блокировкой
   экрана, ответить на вопросы, перезагрузить телефон.
3. Через 24 часа снова откройте этот пункт и выберите «навсегда».

**Проверка, что приложение без интернета:** Настройки → Приложения →
Калькулятор → Разрешения. Интернета там быть не должно. Единственное
разрешение — «Фото и видео»: его приложение запрашивает только изнутри тайника,
при первом добавлении фото.

## Подпись приложения (важно для будущих обновлений)

Чтобы обновления вставали поверх старой версии (не удаляя данные), все сборки
должны подписываться одним и тем же ключом.

- **Постоянный ключ** лежит в `signing/release.p12`. Он **зашифрован паролем**,
  который знает только владелец репозитория. Пароль хранится в секрете GitHub
  `SIGNING_PASSWORD` и у владельца (менеджер паролей). Без пароля файл ключа
  бесполезен.
- Ключ создан **один раз** процессом **Create signing key (one-time)** во вкладке
  Actions. Повторно этот процесс не запустится: если ключ уже есть, он
  откажется работать, потому что новый ключ сломал бы обновления.
- Перед выпуском релиза сборка **проверяет**, что APK подписан именно
  постоянным ключом. Если нет, релиз не выпускается.
- Отпечаток сертификата постоянного ключа (SHA-256, публичная информация):
  `25775ec9ea6de8fd9992d9a9dd827afcb0881fb7f4b4a12433ff1532c7baa92e`
- Пароль нужен только для выпуска обновлений и **не открывает тайник**.
  Не теряйте его: без него нельзя будет выпустить обновление, которое встанет
  поверх установленного приложения.
- Версия 0.1.0 была подписана временным ключом. Поэтому при переходе на
  0.2.0 и новее старый калькулятор нужно один раз удалить (данных в нём нет).
  Дальше обновления ставятся поверх.

## Для разработчика

```bash
./gradlew test            # запустить модульные тесты (логика калькулятора)
./gradlew assembleRelease # собрать APK: app/build/outputs/apk/release/
```

- Язык: Kotlin, интерфейс: Jetpack Compose.
- Версии собраны в `gradle/libs.versions.toml`.
- Логика вычислений (`CalculatorEngine`, `CalculatorController`) не зависит от
  Android и покрыта тестами в `app/src/test/`.
